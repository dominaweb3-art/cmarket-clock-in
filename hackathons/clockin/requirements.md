## Submission focus

C Market is one product with a Seeker-first Android experience. The CLOCK IN submission should demonstrate:

- Android APK installation and cold launch on Seeker.
- Mobile Wallet Adapter wallet connection and approval UX.
- Clear Devnet network, amount, destination, and confirmation state.
- Meaningful Solana interaction with public Explorer evidence.
- Mobile UX quality, multilingual support, branding, error handling, and repeat-use value.
- Public GitHub source, a concise demo video, and a pitch or brief presentation.
