# Submission Materials

This directory tracks the artifacts required for the CLOCK IN submission.

## Required artifacts

- [x] Signed Android APK preserved locally at `artifacts/releases/c-market-0.1.0-release.apk` and intentionally ignored by Git.
- [ ] Public GitHub source repository.
- [ ] Demo video.
- [ ] Pitch deck or brief presentation.

The committed SHA-256 record for the preserved APK is `submission/releases/c-market-0.1.0-release.sha256`.

## Recommended file organization

```text
submission/
  apk/
    README.md
  demo/
    README.md
  pitch/
    README.md
```

Large binary files and final hosted videos may be linked from the final submission form instead of committed to GitHub, unless the organizer requests otherwise.

Before submission, verify that every link works from a clean browser session and that the APK can be installed on a Seeker without a development server.
