# C Market Brand Assets

![C Market — Onchain indexes for a brighter tomorrow](../assets/brand/cmarket-wordmark.png)

The approved brand sheet is retained locally as an ignored source file and is not committed. The repository contains only these approved uses:

- `assets/brand/cmarket-wordmark.png`: primary wordmark for README, documentation, pitch, website, and presentation material.
- `apps/mobile/assets/images/icon.png` and `adaptive-icon.png`: the approved APP ICON for Android and release-store configuration.
- `apps/mobile/assets/images/splash-icon.png` and `favicon.png`: the approved ICON ONLY symbol for splash, small in-app branding, and favicon use.

The MONOCHROME treatment is not included. Do not derive additional logo treatments from these assets.
